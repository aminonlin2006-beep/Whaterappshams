# اپلیکیشن هواشناسی امین — نسخه دقیق بارش برای شعاع ۲۰ کیلومتری شمس‌آباد دزفول

اپلیکیشن بومی اندروید (Kotlin + Jetpack Compose + Material 3) بهینه‌سازی‌شده برای بیشترین دقت ممکن در پیش‌بینی و هشدار بارش برای دایره‌ای به شعاع ۲۰ کیلومتر به مرکزیت شمس‌آباد دزفول (`32.2978N, 48.4283E`).

## ویژگی‌های اصلی و معماری جدید
- **مرکزیت جغرافیایی دقیق**: شمس‌آباد دزفول (`32.2978N, 48.4283E`) و شعاع پایش ۲۰ کیلومتر شامل شمس‌آباد، صفی‌آباد، دزفول، اندیمشک و روستاهای همجوار.
- **شبکه ۱۷ نقطه‌ای همسایگی (Neighbourhood Grid)**: نمونه‌گیری از ۱۷ نقطه شبکه‌ای داخل و روی لبه‌های ۱۰ و ۲۰ کیلومتری برای محاسبه «احتمال بارش در محدوده» ($P_{area}$).
- **تلفیق چندمنبعه و انسمبل**: ترکیب ECMWF IFS (۹ کیلومتر)، ICON جهانی، و اعضای ۵۱گانه ECMWF ENS و ۴۰گانه ICON EPS.
- **دیدبانی زنده زمینی (SYNOP صفی‌آباد WMO 40794)**: دریافت مستقیم و رمزگشایی کدهای FM-12 SYNOP ایستگاه صفی‌آباد از Ogimet (۳٫۶ کیلومتری شمس‌آباد).
- **پایش و رهگیری راداری RainViewer**: اسکن موزاییکی کاشی‌های زوم ۷ RainViewer، استخراج dBZ با جدول رنگ Universal Blue، ردیابی سلول‌های بارشی و محاسبه ریاضی زمان ورود (ETA) و نزدیک‌ترین فاصله.
- **کالیبراسیون آماری MOS (فاز ۶)**: امکان اعمال فایل کالیبراسیون `calibration_40794.json` جهت اصلاح خطاهای سیستماتیک مدل روی داده‌های تاریخی صفی‌آباد.
- **سامانه هشدار ۴ سطحی (RED / ORANGE / YELLOW / GREEN)**: تعیین سطح هشدار به همراه دلیل شفاف و واقعی بر اساس آستانه‌های نام‌دار تعریف‌شده در `Tuning.kt`.
- **رابط کاربری RTL بومی Material 3**: کارت بومی رادار، نقشه Canvas، تفکیک احتمال محدوده از احتمال نقطه، و پانویس شفاف منابع.
